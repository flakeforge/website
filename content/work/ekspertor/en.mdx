## The idea

Ekspertor connects people with verified experts over live video: technology advice, legal questions, health guidance, or career mentoring.

## Planned features

- Live video sessions with screen sharing and file sharing
- Optional call recording
- Hourly billing, with the unused balance refunded

## Where it stands

The project is at the planning stage. The repository holds the description and the license, and the architecture write-up is still to come. If you want to help shape it, the repository is open for issues and pull requests.
